# Упоминания VK

Приложение для Windows: поиск упоминаний сообщества в постах VK и выгрузка результатов в Excel.

[Скачать Упоминания VK 1.1.0 для Windows](https://github.com/ighorrre/vk-mentions/releases/download/v1.1.0/VK-Mentions.exe) · [Все версии](https://github.com/ighorrre/vk-mentions/releases)

## Как пользоваться

1. Запустите EXE. Нужны Windows 10/11 x64, Google Chrome и интернет.
2. Нажмите «Войти в VK» и войдите в своём аккаунте.
3. Укажите ID сообщества или ссылку на него и нажмите «Проверить упоминания».
4. Нажмите «Скачать таблицу Excel».

Первая проверка собирает доступную историю системной ленты упоминаний VK. Повторная быстрая проверка останавливается на знакомой пачке; полная проверка доступна отдельным флажком. Учитываются технические упоминания сообщества в тексте самого поста.

## Таблица Excel

В XLSX отдельные столбцы: дата поста по Москве, полный ID, текст, лайки, комментарии, репосты и кликабельная ссылка. Выгрузка учитывает выбранные фильтры.

Счётчики отражают момент получения поста. Быстрая проверка обновляет только полученные пачки; для обновления старых доступных постов используйте полную проверку. Пустая ячейка означает отсутствие данных, а не ноль.

## Обновление и история

Закройте прежнюю копию через «Закрыть приложение», затем запустите новый EXE. Закрытие вкладки интерфейса само по себе приложение не завершает.

Финальная 1.1.0 содержит тот же бинарник, который был успешно проверен как экспериментальный. Для совместимости сохраняются порт 8775, название окна «эксперимент» и папка `%LOCALAPPDATA%\VK Mentions Experimental`. При первом запуске копируются история и сессия версии 1.0.4; её данные не изменяются. Счётчики старых постов восстанавливаются из сохранённых ответов, если они доступны.

В папке данных хранится личная сессия VK — не передавайте её другим людям. В EXE личные данные не включены. Python, Node.js и Codex устанавливать не нужно.
