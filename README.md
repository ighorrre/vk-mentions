# Упоминания VK

> Обновление 1.0.1 исправляет сохранение входа VK. Проверка антивирусного обнаружения Wacatac для 1.0.0 ещё не завершена; 1.0.1 опубликована как предварительная. Не отключайте защиту ради запуска.

Приложение для Windows, которое собирает посты из системной ленты упоминаний сообщества VK и сохраняет историю проверок. У каждого поста есть ссылка на оригинал.

[**Скачать VK-Mentions.exe**](https://github.com/ighorrre/vk-mentions/releases/download/v1.0.1/VK-Mentions.exe)

## Запуск

Нужны Windows 10/11 (64-бит), установленный Google Chrome и интернет.

1. Запустите `VK-Mentions.exe`. Откроются окно управления и интерфейс приложения в браузере.
2. Пройдите встроенное обучение, нажмите «Войти в VK» и войдите в свой аккаунт.
3. Укажите ID или ссылку на сообщество и нажмите «Проверить упоминания».

После входа окно VK можно закрыть: проверки выполняются в фоне, пока приложение включено. Первая проверка собирает доступную историю, повторные быстрые проверки останавливаются на знакомой пачке. Для проверки всей ленты есть отдельный флажок: быстрая проверка может пропустить новые упоминания глубже в старой ленте.

История и сессия хранятся на вашем компьютере в `%LOCALAPPDATA%\VK Mentions`. Эта папка содержит данные входа; не передавайте её другим людям. В распространяемом EXE нет сохранённой сессии и личной истории.

Чтобы завершить работу, закройте небольшое окно управления или нажмите в нём «Закрыть приложение». Закрытие вкладки интерфейса не завершает приложение.

Приложение учитывает технические упоминания сообщества в тексте самого поста. Оно использует ленту, доступную вашему аккаунту, и не выполняет глобальный поиск по всему VK. При запросе повторного входа или CAPTCHA потребуется ручное действие в окне входа.

## Обновление

Закройте приложение и замените EXE новым файлом из Releases. Локальная история сохраняется.

Сборка 1.0.0 не имеет цифровой подписи Windows. SHA256 и подробная инструкция доступны рядом с EXE в Releases. Лицензии включённых сторонних компонентов находятся внутри сборки и в файле THIRD_PARTY_NOTICES.txt.
